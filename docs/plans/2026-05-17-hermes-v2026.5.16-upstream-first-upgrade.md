## TDD Gate

This inventory is documentation-only, so TDD does not apply to this file.
Every code port from the local branch must follow Red-Green-Refactor:

1. Write or identify a focused upstream-base test that fails for the missing
   local behavior.
2. Confirm the failure reason.
3. Port the minimal implementation.
4. Re-run the targeted test and the nearest suite.
5. Refactor only after green.
