## Final Convergence Closure

The upgrade is closed from a core-port perspective. The branch keeps only the
local changes that still lack an upstream-equivalent mechanism and have focused
tests. Everything else from `feat/hermes-custom-autonomy` stays out of core
unless a future failing test proves a current live-runtime contract.

| Old local surface | Closure | Replacement path |
| --- | --- | --- |
| Layer-2 memory and review tools | `minimal no-loss bridge` | Upstream has `agent.memory_provider`, `hermes memory setup/status`, provider tool routing, bundled memory plugins, and cron `wakeAgent` gating, but live cron still needs the Layer-2 sidecar ledger contract. Keep only scheduler ingestion, local ledger, wake-gate signals, and deterministic consolidation. Do not port old `layer2_memory` / `layer2_review` tool surfaces. |
| Local `/loop` runtime | `retired` | Use upstream Ralph `/goal`, `/subgoal`, gateway Kanban dispatch, checkpoints, and `resume_pending` session recovery. Rebuild nothing from `hermes_loop/*` unless a future upstream-base failing test proves a specific live contract is missing. |
| Loop-specific gateway recovery | `retired` | Keep only generic recovery bugs already ported, such as placeholder-media fallback and closed-stdout handling. Do not revive loop-specific recovery state. |
| Story/video and Taiwan creative skills | `move-to-runtime-skills` | Keep these as runtime skills or a local plugin under Hermes home, not release-upgrade core patches. |
| Arbitrary local image references | `discard-from-core` | Support only current-turn uploaded references in `image_generate`. Local filesystem references stay rejected unless a separate opt-in plugin/config design proves necessary. |
| Release/adoption planning docs | `discard-from-core` | Keep historical plans as context only. Do not copy old planning docs into the upstream-base branch unless they describe active behavior. |
| Old security hardening patches | `upstream-equivalent` | Dashboard plugin auth, quick-command redaction, SSRF coverage, and image token estimation are handled upstream. Keep local copies out of this branch. |

## TDD Gate

This inventory is documentation-only, so TDD does not apply to this file.
Every code port from the local branch must follow Red-Green-Refactor:

1. Write or identify a focused upstream-base test that fails for the missing
   local behavior.
2. Confirm the failure reason.
3. Port the minimal implementation.
4. Re-run the targeted test and the nearest suite.
5. Refactor only after green.
