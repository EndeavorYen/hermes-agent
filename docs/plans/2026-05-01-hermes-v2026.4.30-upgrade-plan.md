## Non-negotiable safety rules

1. **Merge, do not rebase.** This branch is customized; preserve local commit topology.
2. **Create and push a rollback checkpoint before restart or deeper changes.**
3. **Do not enable Curator mutation immediately.** First inspect config/docs, confirm pinned/custom skills are protected, then run status/dry-run/report-only if available.
4. **Do not treat optional `hermes doctor` warnings as rollback triggers.** Separate real runtime blockers from optional provider/tool warnings.
5. **Do not refactor while resolving conflicts.** Resolve only enough to compile/import and preserve existing behavior. Architecture alignment is a later slice.
6. **Do not include unrelated untracked files in upgrade commits.** Only add intentional files.
7. **Stop if gateway cannot deliver a Slack reply after upgrade.** Slack DM delivery is the live smoke test for this environment.
